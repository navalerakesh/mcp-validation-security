## Authority And Compatibility

Schema inspection corrections are grounded in JSON Schema draft 2020-12: [Core sections 4.3.2 and 10.3.1.2](https://json-schema.org/draft/2020-12/json-schema-core) and [Validation sections 6.1.1, 6.4.2 and 6.5.3](https://json-schema.org/draft/2020-12/json-schema-validation), published 2022-06-16. Boolean schemas, type alternatives, omitted minItems and exact property names are not new MCP requirements. Advisory inspection remains distinct from schema conformance and does not resolve arbitrary references or prove model accuracy.

Configuration acceptance is intentionally stricter than 2.0.1. The canonical document type remains V2; additive result contracts through `2.3.0` and their migration rules are described in [schema compatibility](SchemaCompatibility.md). Raw optional transport session identity is excluded from serialization for privacy, while typed session validity/propagation outcomes remain. Selective error probing is an additive API whose default implementation rejects unsupported selection instead of dispatching a broader suite. Catalog/policy revisions identify interpretation changes. Historical released-package diagnostics remain historical and are not rewritten as corrected-product evidence. No SDK, protocol-version pin or package version is changed.
